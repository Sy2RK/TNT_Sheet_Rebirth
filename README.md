# TNT AI Sheet — Univer 开源版

基于 Univer 1.0.3 的表格应用。表格渲染、公式计算、工作表、选区、原生菜单、剪贴板和撤销重做全部由 Univer 管理。旧自制网格、WorkbookStore 和 HyperFormula 已删除。

## 运行

```sh
npm ci
npm run dev
```

打开 http://127.0.0.1:5173 。生产构建使用 `npm run build`，本地预览使用 `npm run preview`。

## 表格能力

`src/sheet/plugins.ts` 在创建编辑器前注册 37 个开源插件，包括：

- 表格和富文本编辑、公式、数字格式、命名范围、多工作表、冻结、保护范围和工作表权限。
- 排序、筛选、条件格式、数据验证、超链接、查找替换。
- 图片、批注、注释、表格对象、十字高亮、水印扩展。
- 原生工具栏、菜单、公式栏、工作表标签、快捷键和撤销重做。

所有 Univer 依赖固定为 1.0.3（独立发布的传递依赖按官方包约束）。不安装 `@univerjs-pro/*`，不使用 Pro 授权、协作后端或商业文件转换服务。水印等可编程扩展保留官方 API，不额外发明自定义工具栏按钮。

窄屏触摸设备初始化官方移动 UI 插件；桌面使用桌面 UI。移动支持仍是上游实验功能，真实手机浏览器、软键盘及麦克风应另外验收。尺寸变化不会销毁正在编辑的工作簿或自动切换 UI 模式。

## 文件与保存

- **保存工作簿**：下载 `.univer.json`，保留原生工作簿、样式、插件资源，并保存至本机 IndexedDB。
- **打开**：支持 `.univer.json` 和 `.xlsx`，替换当前工作簿前提示保存。
- **导出 XLSX**：使用开源 ExcelJS 转换 Univer 快照，支持基础值、公式、多工作表、常见字体/填充/对齐/边框/数字格式、合并、行高列宽、隐藏和冻结。
- XLSX 转换是兼容适配层，**不是完整保真转换**。图片、条件格式、数据验证、表格对象、批注、富文本细节等以 `.univer.json` 为完整备份；UI 导出后也会提示。ExcelJS 不参与在线编辑、计算、状态或历史。
- 新版自动保存键为 `tnt-ai-sheet/workbooks/univer-current-v1`。旧版 `current` 数据未删除，也不会被错误当作 Univer 快照读取。旧格式没有自动迁移。
- 自动保存只在开启时生效。手动输入的 API Key 只驻留内存；开发模式可从本地配置恢复。

## AI 与语音

支持 Ask / Edit / Agent、多模型配置、导入和管理 JSON Skills。本地规则支持统计、公式查看、清洗、汇总、排序和格式指令；模型调用仍使用 HTTP Provider。

新配置默认使用 DeepSeek V4.1 Flash（`deepseek-flash`）。在偏好设置输入 API 地址与 Key 后自动读取服务商模型列表，并以服务端显示名称呈现下拉选项；可刷新列表或为不提供列表的服务手动填写。支持 OpenAI 兼容接口、DeepSeek、通义千问、Ollama，以及 Claude / Gemini 的认证、列表格式与分页。已有模型仍可用时保留用户选择；更改连接或关闭设置会取消旧的列表请求。本地模式仍可通过模型服务菜单选择。

千问默认选 `qwen3.8-flash`，使用百炼 `/api/v1/models` 分页目录和模态信息筛选文本模型，不混入图片、ASR、TTS。目录中的模型不代表 Key 均有调用权限，最终以实际请求为准。该目录接口的浏览器跨域预检实测失败，开发服务提供限定官方目录地址的本机中转；静态生产部署需要配置同类后端中转，或手动指定模型。对话请求仍走服务商兼容接口。

千问对话采用流式请求，合并最终文字后再校验和执行操作计划，兼容仅支持流式输出的模型。思考内容不会作为操作指令。显式使用 `/clean` 等技能命令时限制可用操作；普通指令自动匹配的技能提供处理规则，允许清理加排序等组合任务。

开发配置放在根目录 `config.local.json`：复制 `config.example.json` 并填写自己的 Key。真实配置不随仓库分发；文件被忽略且禁止通过开发服务直接下载。启动或刷新开发页面后会自动载入，切换服务会切换对应 Key；修改 URL 时会清除不再匹配的自动密钥。手动覆盖密钥只影响本次会话，不回写文件。配置读取仅开放给本机同源请求，且不加入生产资源或 PWA 缓存。生产模式继续手动配置，不会读取此文件。

AI 读取当前选区及限量上下文，通过受控工具调用 Univer Facade API。修改先在隔离的 Univer 实例中验证，成功后在当前工作簿内使用原生 `beginUndoRedoGroup(..., 'append')` 提交；一次撤销恢复整条指令。Ask 禁止写工具，修改期间的版本冲突和取消会阻止提交，大范围删除等操作预览确认后执行。

语音使用独立 Web Speech 适配器。支持按住麦克风或长按已选区域，锁定目标、实时显示识别文字，松手提交到同一 AI 引擎。浏览器需要支持语音识别并授予麦克风权限；自动测试使用模拟识别器，未验证真实录音服务。

语音界面区分服务启动、聆听和等待最终文字；启动前松手、重复停止、超时和空结果均有处理。授权麦克风不代表浏览器识别服务可用，DeepSeek Key 也不提供 ASR。故障判别、检查边界和专用流式 ASR 建议见 `docs/SPEECH_ASSESSMENT.md`。

千问最新 ASR 与其他方案的真实接口测试和选择建议见 `docs/ALIYUN_ASR_EVALUATION.md`。本次评测六个 ASR 模型，未切换语音按钮的 Web Speech 实现；配置文件的 `asr` 部分记录评测候选，尚不是应用中生效的语音设置。

## 代码结构

```text
src/sheet/       Univer 插件装配、实例生命周期、原生快照、地址工具
src/ai/          模型 Provider、上下文、Skills、工具校验与 Univer 操作适配
src/platform/    文件转换、下载、IndexedDB、设置、语音与平台接口
src/ui/          AI 侧栏、设置与 Skills 弹窗
src/App.tsx     应用外壳和输入协调（不实现表格内核）
```

`SheetRuntime` 是集成层，不保存第二份工作簿，也不重新实现公式或撤销。工作簿数据唯一来源是 Univer。测试调试入口 `window.__tnt` 仅在开发模式存在。
